# 点菜收银系统

店里用的点菜收银系统，纯前端，不用装服务器，浏览器打开就能用。

## 能干啥

- 12 张桌（内 1～内 4、外 1～外 6、打包 1～打包 2）
- 分类点菜，130+ 道菜，啤酒能批量点
- 菜单外的菜可以临时加，纸巾/打包盒这些额外费用也能记
- 小票：预览、生成、复制文字、存成图片（离线也能用）
- 菜品增删改查，支持拼音首字母搜
- 换桌、清桌、新桌
- 手机按返回键不会退出，数据自动存本地

## 怎么用

- 手机：浏览器打开 `index.html`，点桌号 → 点菜 → 小票
- 电脑：同一个页面，自动变成宽屏

直接双击 `index.html` 就行。想在线用也能挂 GitHub Pages。

> 数据存浏览器本地，换手机/清缓存会丢，营业建议固定一台设备。

## 目录

```
index.html            页面骨架
css/style.css         样式
js/dishes.js          菜品数据（改菜价就改这）
js/app.js             逻辑
vendor/html2canvas.min.js   存小票图片用的库（本地化了）
```

改菜价、加菜直接动 `js/dishes.js`，或者进系统里「菜品管理」改。
